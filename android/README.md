# ZorixOS 2.0 Liquid Experience

Android UI simulator with iOS-style home, apps, Dynamic Island, lock screen and HyperOS 4-inspired Settings.

Features: English by default; first-run Hello, language, region, privacy and appearance wizard; optional Simplified Chinese in Settings; reactive Dynamic Island for music/timer/focus; deferring remote artwork loads; Android immersive full-screen with WebViewAssetLoader; app action sheets and demo data export.

This is NOT a ROM or a system launcher. Controls are demo UI; Android can still show critical permission dialogs, calls or notifications.

Build with Gradle 8.10.2, JDK 17, Android SDK 35: gradle :app:assembleDebug --no-daemon
