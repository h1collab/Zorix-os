# ZorixOS

ZorixOS is a lightweight Alpine Linux based operating system focused on speed, minimalism, security and AI integration.

## Features

- Alpine Linux base
- Extremely lightweight
- Fast boot performance
- Optimized for low-resource hardware
- Modern terminal environment
- AI-ready infrastructure
- Custom Zorix tooling
- Debian package compatibility layer
- Portable ISO distribution

## Editions

- Desktop Edition
- Minimal Edition
- Server Edition

## System Requirements

### Minimum

- 2 GB RAM
- 10 GB Storage
- x86_64 CPU

### Recommended

- 4 GB RAM
- SSD Storage
- Multi-core CPU

## Installation

Boot the ISO image:

\`\`\`bash
dd if=zorixos.iso of=/dev/sdX bs=4M status=progress
\`\`\`

Then reboot and start installation.

## Philosophy

ZorixOS combines Alpine Linux minimalism with modern AI-focused tooling and developer workflows.
